## 离线复核方式

1. 将四个开发 ZIP 分别与对应检查点的 `reset_review_details.source_archive_sha256` 比对。此次四个哈希全部相符。
2. 解包后，对每个包含 `run-ledger.json` 的批次目录执行 `python -m agent_privacy.scorer <批次目录> --output <新的输出文件>`。输出的 `summary` 应与检查点的 `report` 内容一致。此次另用 `contracts.validate.validate` 校验了全部 64 个运行 bundle，并用 `grade_bundle` 复核了每条 `outcome.json`。
3. 用每个尝试的 `conversation.json` 按工具调用编号配对请求和返回值，再用 `reset.json` 检查剩余绑定为 0、对话已清空且审计记录保留。用账本 `snapshots[0].path` 定位冻结文件，检查 H1 尝试中的副本哈希。
4. 身份检查点逐对列出原身份与单字段变更的结果。原始 `identity/observations.jsonl` 另含每次用量，操作人可据此核对身份阶段的令牌数。
