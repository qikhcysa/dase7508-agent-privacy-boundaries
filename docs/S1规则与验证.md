# S1 固定电话号码脱敏，规则 v1

## 范围

S1 是在统一发送入口运行的固定模式实验基线。S0 和 S1 使用相同的隐私指令，实验差别是出站内容脱敏。

## 接入方式

使用经过共享接口校验的运行配置，将 run.policy 设置为 S1，其余构造参数与 S0 相同。创建 EgressAdapter 后，控制器请求调用 send_controller，模拟云端释放依次调用 record_proposal 和 release_to_cloud。

S0、S1、S2 是分别运行的对照策略。S1 仅执行固定模式脱敏，不接受 static_allowlist 配置；S2 使用固定白名单，不叠加 S1 脱敏。混用配置会在创建日志或发送数据之前报错。

每次尝试使用新的日志路径。可信运行程序应完整登记消息中使用的对象和字段，并按下文约定放置文本内容。输入格式见[共享接口说明](contracts/README.md)。

## 固定规则

规则标识为 s1_phone_v1。匹配连续八位 ASCII 数字，前后不能紧邻其他 ASCII 数字。可带 852 或 +852 区号，区号与号码之间允许没有分隔，或仅有一个空格，或一个 ASCII 短横字符。号码内部不接受分隔。匹配整个号码及可选区号，统一替换为 [PHONE_REDACTED]。

规则不读取敏感标签、任务授权或样本答案，不为合成标记增加例外，也不根据正式实验结果调节。修改规则需要明确版本与开发依据，并在正式实验前由 #22 冻结协议。

| 输入 | 预期 |
| --- | --- |
| 87654321 | [PHONE_REDACTED] |
| +852 87654321 | [PHONE_REDACTED] |
| 8765 4321 | 保留，已知漏检 |
| 13800138000 | 保留，不属于八位模式 |
| SYNTHETIC_PRIVATE_EVENT | 保留，已知事件标题泄露 |
| 12345678，普通参考编号 | 被替换，已知误删 |
| 09:00 至 09:30 | 保留 |

## 处理边界

模拟云端仅处理已选字段的值，递归处理字典和列表内的字符串，保留键与非字符串类型。任务身份、用途、句柄和字段清单保持原样。

控制器请求处理各条消息的 content，支持文本、空值和仅含文本的内容列表。可解析的 JSON 内容先解码再处理字符串值，因此 JSON Unicode 转义不能直接绕过字符串匹配。JSON 数据中的键保留，值作为内容处理，不根据名为 scope 或 handle 的键跳过脱敏。JSON 字符串重新编码可能改变空格等表现形式。

外层 API 参数、模型标识、消息角色、工具调用 ID、工具定义和 release 等工具的控制参数不做替换。save_memory 的自由文本 content 参数做脱敏。可信运行程序必须把自由数据放在受支持的内容位置，不得塞进工具定义或控制字段。多模态内容和不合法的 save_memory 参数在 S1 下报错，不静默发送。普通文本内恰好像电话号码的引用仍可能被误删，S1 不做语义识别。

脱敏先于请求序列化、载荷哈希、发送记录和传输。两条路径共用现有发送实现。出站决定的 reason 为 s1_phone_v1。本地注册表、调用者输入和原始提议不被改写。原始输入、提议及模型响应仍可包含敏感合成值，它们是本地审计证据，不是脱敏后的出站正文。

## 验收与复跑

使用 Python 3.11 或以上版本，并安装仓库原有 requirements 文件声明的 jsonschema 依赖。在仓库根目录执行 python verify_s1.py。依赖安装遵循[共享接口说明](contracts/README.md)。

入口先运行 tests 目录中的现有与新增测试，再校验两份接口示例。测试通过后生成独立的 artifacts 运行目录，包含 S0、S1 与 F0、F1 四种组件输入的记录，各记录均通过 v1 bundle 校验，最终输出 summary.json。

新增测试覆盖号码边界、嵌套内容、JSON 转义、协议字段保留、不支持输入拒绝、已知漏检和误删、每次发送重新处理、本机 HTTP 实际接收字节与预写记录一致、模拟云端接收记录一致、合法派生时段保留、原始数据不变以及记录失败时停止发送。S0 的现有测试保留。

F0 与 F1 在此仅为组件出站输入，不是真正注入日程故障。控制器演示为脚本，HTTP 测试只访问本机回环服务，没有真实模型或付费调用。事件标题泄露是保留的限制观察，测试通过不代表所有隐私已被保护。

原始运行记录保存在本地生成目录，可通过同一入口重新生成。任务进度与人工审查记录见 [Issue #13](https://github.com/qikhcysa/dase7508-agent-privacy-boundaries/issues/13) 和关联 PR。
